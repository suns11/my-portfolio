# Basic Portfolio Website

A simple, responsive personal portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and current year

## Before publishing
1. Open `index.html`.
2. Replace `your-email@example.com` with your real email address.
3. Replace the LinkedIn homepage link with your LinkedIn profile URL.
4. Add more projects if you want.

## Deploy with GitHub Pages
1. Create a new public repository on GitHub, for example `my-portfolio`.
2. Upload all four files to the repository's root folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes. GitHub will show your live website URL in the Pages section.

No build command or framework is required.
